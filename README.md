Ohrwurm is dealing with the topic of overstimulation through everyday unavoidable city noises. Ohrwurm aims to propose an alternative to Noise Cancelling. 

Instead of shutting out disturbing noises the portable device alters them to be easier for the listener to endure. Incorperation instead of cancelling. There are two options for the user to alter their sound experience. Filter one is a generative drum maschine that creates beats based on Input parameters. Tempo, beat type and volume can thus be controlled by users. Using the noises surrounding  the user. If the noises change the beat changes. The second option is a live pitcher. If a certain frequency occours the filter turns on and expands that tone to its major chord. The threshold can be altered by the user. 

The audio filters coded in MAX MSP relie on a research about psychoacoustics, especially the topic of masking.
