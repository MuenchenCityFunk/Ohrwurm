Ohrwurm is dealing with the topic of overstimulation through everyday unavoidable city noises. Ohrwurm aims to propose an alternative to Noise Cancelling. 

Instead of shutting out disturbing noises the portable device alters them to be easier for the listener to endure. The Filter consit of two components. The first one is the 'construction detection'. The surrounding noises are detected through different filters (lowpass, highpass, etc.). With the help of a given threshoold, certain sound snippets are recorded. These snippets are used in the second component called drumnoise maschine. Here the user can create a beat pattern with a generative drum maschine. Using the noises surrounding noises the beat changes when the noise changes. 

The audio filters coded in MAX MSP relie on a research about psychoacoustics, especially the topic of masking.
